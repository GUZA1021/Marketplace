# Distributed Online Marketplace

University project developed as part of the Distributed Web Applications course.

The project demonstrates the design and implementation of an online marketplace using Flask. The application was first developed as a monolithic web application before being refactored into a microservice architecture to explore distributed system principles.

---

## Features

- User authentication
- User registration
- Marketplace listings
- Listing search and filtering
- Buyer-seller communication
- Reviews and ratings
- Profile management

---

## Monolithic Architecture

The first version of the application was implemented as a monolithic Flask application using:

- Flask
- SQLAlchemy
- SQLite
- Flask Login
- WTForms
- Jinja Templates
- Bootstrap
- Docker

---

## Microservice Architecture

The application was later redesigned into independent services:

- Frontend Service
- Authentication Service
- Listing Service
- Review Service

Each service owns its own database and communicates through HTTP requests.
